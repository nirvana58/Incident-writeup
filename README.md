# Incident Write-up

A defensive cybersecurity incident report documenting an **authorized phishing simulation** conducted in an isolated lab.

## Report

- [IR-SIM-2026-0603-01 — Credential-Harvesting Phishing Page](./IR-SIM-2026-0603-01.md)

## Overview

The report covers the simulation timeline, technical observations, redacted indicators of compromise, detection and response recommendations, impact assessment, and MITRE ATT&CK mapping. It also distinguishes the original lab activity from a later scan of a separately hosted copy.

## Scope and Safety

This was a controlled learning exercise. Only dummy test values were used; no real users, accounts, or credentials were involved. Infrastructure indicators are redacted in the public report.

## Disclaimer

For educational and defensive security purposes only. Findings and recommendations should be interpreted within the documented scope and evidence limitations.
